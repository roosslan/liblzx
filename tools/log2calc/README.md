# log2calc

Генератор таблиц `log2_fixed_table_0` и `log2_fixed_table_1` в
`liblzx/liblzx_lzx_compress.c`. Таблицы используются функцией
`log2_fixed_fast_normalized` для вычисления двоичного логарифма в
фиксированной точке: оценка стоимости символов при близком к оптимальному
разборе обходится без арифметики с плавающей точкой, поэтому результат
сжатия не зависит от настроек FPU и оптимизаций компилятора.

Программа написана автором оригинальной liblzx и использует `_udiv128` из
MSVC (`<intrin.h>`), поэтому собирается только компилятором Microsoft
(x64). В сборку библиотеки она не входит и нужна только для повторного
получения таблиц, например при изменении их разрядности.

Для сборки достаточно выполнить в «x64 Native Tools Command Prompt»:

```
cl /O2 /EHsc log2calc.cpp
```

Программа выводит значения таблиц в стандартный вывод.
